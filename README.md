# Free Bible App

App para Biblias gratis.

## Descripción

Free Bible App es un proyecto web simple orientado a ofrecer acceso gratuito a contenido bíblico.

## Tecnologías

- HTML (90.6%)
- CSS (7.4%)
- JavaScript (2%)

## Contenido del repositorio

- `spa-rv1909.usfx.xml`: archivo fuente bíblico en formato USFX.

## Cómo ejecutar localmente

1. Clona el repositorio:

   ```bash
   git clone https://github.com/robertorosacarrillo08-beep/Free-Bible-app.git
   ```

2. Entra al directorio del proyecto:

   ```bash
   cd Free-Bible-app
   ```

3. Abre el archivo HTML principal (por ejemplo, `index.html`) en tu navegador.

## Objetivo

- Facilitar el acceso gratuito a Biblias desde una interfaz web sencilla.
